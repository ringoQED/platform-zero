FPS game using Three.js and runs on browser
This is my first attempt to see how much AI can make with a free plan from e.g. gemini to make a game of this complexity.
The game features a simple underground MTR station (Hong Kong style) with simple weapons like pistol and shotgun. Monsters will be added later on and some more enhancement like stuffs will be added to the scene, train will be added to the platform door etc.

As complexity increases, if I realize that free AI plan cannot finish the job, I may try switching to some cheap paid plan to see if this can be done.
